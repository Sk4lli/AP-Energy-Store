Project "Archipelago Energylink Store"

Build a purely browser-based client for Archipelago.
Only HTML, CSS and JavaScript are to be used.
The connection to Archipelago uses archipelago.js (https://github.com/ThePhar/archipelago.js/).

The goal is a web based item store built on top of the EnergyLink system.
The store has several pages (progress items) with "locations" to buy (one location per progress item).
The config YAML states how many progress items there are and how many locations each of them has,
i.e. the locations per page. 5 to 10 locations per page are allowed.
The currency is joules, straight from the EnergyLink system, which is based on the joules from Factorio.

The web application also has a built-in console acting as a text client, for commands and error logs.

The language of the web application is loaded from a selectable file such as 'lang/de_DE.lang'.
